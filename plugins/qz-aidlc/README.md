# qz-aidlc · QualiZeal AI-DLC Studio plugin

The QualiZeal AI Center of Excellence's governed way to do agentic AI work in Claude: lanes that architect, spec,
build, evaluate, test, audit, deliver, demo, bid and write office decks, workbooks and mail; a full-stack developer
agent; fresh-eyes spec reviewers; a vectorless RAG (retrieval-augmented generation) kit built live by stage; the
Knowledge Fabric; and a harness around all of it - a policy guard that reads every command on a line, per-turn
undo, goal mode, hillclimbing on a measured number, routing that fits the model and effort to the task, an audit
chain, a run ledger and report cards.

Install in Claude Code 2.1.275 or later:

    /plugin install qz-aidlc --marketplace qualizeal-aicoe/Qualizeal_AIDLC_For_InHouse

Start with `/qz-aidlc:qz` and say what you need, or `/qz-aidlc:qz-help` for every command. Setup:
`/qz-aidlc:qz-setup`. Full documentation, the setup guide and third-party notices are in the repository root of
`qualizeal-aicoe/Qualizeal_AIDLC_For_InHouse`. Needs Node.js and Python 3.10 or later on a laptop. Internal to QualiZeal.
