---
name: qz-client-voice
description: Rules for anything a client reads - proposals, decks, SOWs, RFP answers, demo text, emails drafted for client use
user-invocable: false
---

- Plain, human-sounding English; few ideas per slide or paragraph; no hype words (seamless, leverage, cutting-edge, unlock, empower, holistic).
- Position QualiZeal as "we will build it for you"; never say we reuse existing assets, kits or accelerators.
- Expand every acronym on first use: "AI Development Life Cycle (AI-DLC)".
- Planned work is never written as done. Numbers carry their basis; economic figures are directional unless measured.
- Comparable work is described anonymously ("a global airline", "a payer platform") unless the person says the client name is cleared.
- Never include cost rates, pay rates, margins or anything from `.qz/internal/`.
- Never include a rate card. A rate appears only as the rate of a role we priced for this client, in the commercials.
- Run `voice_check` on every client file and fix each FAIL before showing it.
